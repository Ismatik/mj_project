# MJ Project

Website, website admin and salon CMS for **Mavzunai Jovid — Gallery of Beauty MJ** (Dushanbe).

- `PLAN.md` — scope, decisions, releases.
- `design/` — HTML prototypes of the designs to implement:
  - `Salon CMS Dashboard Main.dc.html` — salon CMS
  - `Mavzunai Jovid Website Main.dc.html` — public website
  - `Site Admin.dc.html` — website admin
  - `Loader Options.dc.html` — loader variants (chosen: monogram)
  - `mj-fx.js` — shared effects; `support.js` — prototype renderer; `image-slot.js` — photo slot component; `_ds/` — base design system
